## Hi, I'm Vicente 👋

Electronic Engineering student at **Universidad Técnica Federico Santa María** (Valparaíso, Chile). I build prototypes where hardware and software meet: a brain–computer interface that moves a robotic arm, ESP32 firmware, computer vision that runs in the browser, and web tools for the lab.

I'm interested in R&D, instrumentation and robotics, especially for aerospace, energy and electric-mobility applications.
